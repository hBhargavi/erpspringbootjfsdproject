## **📘 Educational ERP System (Java Full Stack Project)**

As part of our **Java Full Stack Development & Microservices training**, my team and I successfully built a **comprehensive Educational ERP System** designed to streamline academic & administrative workflows within institutions.

This ERP platform supports multiple user roles and provides modules essential for efficient campus operations such as **attendance tracking, timetable management, course handling, feedback, exams, and fee payments**.

---

## 🔥 **Key Highlights**

| Feature        | Details                                                                         |
| -------------- | ------------------------------------------------------------------------------- |
| **User Roles** | Admin, Faculty, Student                                                         |
| **Modules**    | Course, Attendance, Timetable, Examination, Feedback, Payment                   |
| **Purpose**    | Automate workflows and reduce manual administration in educational institutions |

---

## 🛠 **Technical Stack**

| Layer          | Technologies                          |
| -------------- | ------------------------------------- |
| **Backend**    | Spring Boot                           |
| **Frontend**   | HTML, CSS, JSP                        |
| **Database**   | MySQL                                 |
| **Tools Used** | Maven, GitHub, Tomcat/Embedded Server |

---

## 🚀 Features

* Admin can manage faculty, students, courses, and modules
* Faculty can manage attendance & exam records
* Students can access timetable, attendance, grades & payment details
* Feedback & review mechanism integrated
* Secure login for each user type
* Modular, scalable project architecture
